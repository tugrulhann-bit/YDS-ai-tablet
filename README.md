# YDS AI — tablet sürümü

Kişisel YDS hazırlık uygulamasının derlenmiş, yayımlanan kopyası (v0.10.1). Kaynak kod, API anahtarı ya da kişisel veri içermez.

- Adres: https://tugrulhann-bit.github.io/YDS-ai-tablet/
- iPad/iPhone: Safari'de aç → Paylaş → Ana Ekrana Ekle.
- Gemini anahtarı yalnızca girildiği cihazın tarayıcısında saklanır (Ayarlar → Yapay zekâ).
- Veriler her cihazın kendi tarayıcısında durur; aktarma Ayarlar → yedek ile yapılır.
